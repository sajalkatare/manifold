# it_support.md  (dept=engineering, access=internal)

## VPN Errors
Error code ERR-5021 indicates VPN authentication failure. Reset your VPN-7 profile from the self-service portal and retry. If ERR-5021 persists, file a ticket with the network team.

## Laptop Refresh
Laptops are refreshed on a 36-month cycle. Submit Form IT-09 to request an early refresh for hardware faults.

## Production Access
Production database access requires approval ticket PROD-ACCESS-01 plus a hardware security key. Access expires after 90 days.
